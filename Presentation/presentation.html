05

Der Herzschlag

Wann passiert was? (Apache Airflow)

Das System "atmet" in definierten Zyklen. Wir streamen nicht alles in Echtzeit, sondern nutzen intelligente Intervalle.

⏰

10-Minuten-Takt

Der Puls: Echtzeit-Daten (Fchg). Schnell genug für verlässliche Updates, schonend für API-Limits.

🌤️

6-Stunden-Takt

Wetter-Updates: Alle 6 Stunden werden Wetterdaten aktualisiert.

🔄

Idempotenz

Wenn ein Zyklus ausfällt, wird er nachgeholt. Keine Daten gehen verloren.

🔀

ELT-Prozess

Transformation findet nach dem Laden statt. Rohdaten bleiben immer erhalten.

07

Qualitätssicherung & Monitoring

Vertrauen ist gut, Kontrolle ist besser

🔍

Duplikat-Problem

APIs senden oft redundante Daten. Lösung: Intelligente Deduplizierung via SQL (DISTINCT ON Batch-IDs).

📧

Monitoring & Alerting

Automatische E-Mail-Benachrichtigung bei Failure direkt vom Server. Das System überwacht sich selbst.

♻️

Idempotenz

Jeder Job kann beliebig oft wiederholt werden, ohne Datenmüll zu erzeugen.

Wenn eine Pipeline bricht, erfolgt eine Alarmierung.

Die Herausforderungen

Hürden auf dem Weg zum System

Ein Informationssystem ist nur so gut wie die Daten, die es füttern.

  • Verständnis & Dokumentation: Deutsche Bahn liefert XML ohne Attribut-Dokumentation. Extremer Aufwand für Reverse-Engineering und Mapping der Attribute.
  • Daten-Bereinigung: Inkonsistente Formate und fehlende Mappings mussten bereinigt werden.
  • Prototyp-Status: Das System funktioniert, aber die Komplexität der Datenquellen war höher als erwartet.
  • Big Data Performance: Implementierung von Paginierung im Dashboard, um Millionen von Datensätzen flüssig darzustellen.
09

Das Gehirn

Wie das System die Zukunft vorhersagt

Wir nutzen ein Long Short-Term Memory (LSTM) Netzwerk. Aber warum keine einfache Regression?

📊
Input
Sequenz der letzten 5 Stationen + Wetter-Kontext
🧠
LSTM Brain
2 Layers (je 64 Neuronen) + Dropout (0.2)
🎯
Output
Vorhersage: Verspätung in Minuten
📅

Training: Stündlich (Online Learning)

Adaptives System: Lernt kontinuierlich aus den letzten 24h, um auf aktuelle Wetterlagen und Störungen zu reagieren.

💾

Datenbasis: >3,4 Mio.

Deep Learning braucht Masse ("Big Data"), um seltene Muster (z.B. Sturmfluten) zu lernen.

⚡

Inferenz: Alle 15 Min

Echtzeit-Warnung für Passagiere basierend auf dem aktuellen 4-Stunden-Fenster.

🔥

Framework: PyTorch

Flexibilität für komplexe neuronale Netzwerkarchitekturen.
